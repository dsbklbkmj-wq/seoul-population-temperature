# 서울, 사람은 떠나고 집값은 오르다

2005 · 2010 · 2015 · 2020 · 2025 — 5개 시점으로 본 서울 25개 자치구의 인구와 아파트 가격 변화 인터랙티브 지도입니다.

## 핵심 메시지 (데이터에서 자동 계산)

- 서울 주민등록인구: 2005년 10,297,004명 → 2025년 9,579,177명 (**약 71.8만 명, -7.0%**)
- 서울 아파트 평당가(중앙값): 2010년 1,725만원 → 2025년 4,670만원 (**약 2.7배**)
- 강남·서초·송파·강동은 인구가 늘었고(+2.7~8.0%), 노원·도봉·강북은 20% 안팎 줄었습니다.

## 데이터

| 파일 | 내용 | 출처 |
|---|---|---|
| `data/population.js` / `.csv` | 구별 주민등록인구 5개 시점 | 서울 열린데이터광장 |
| `data/price.js` / `.csv` | 구별 평당가(만원/평) = 전용면적 ㎡당 거래가 **중앙값** × 3.3058 | 국토교통부 실거래가 |
| `data/price_detail.csv` | 구별 거래건수, 평균 거래가, ㎡당 중앙값, 표본부족 여부 | 〃 |

### 집계 방법
국토부 자료는 아파트 개별 거래 내역이므로 `scripts/build_data.py`가
1. 헤더 앞 설명 15줄을 건너뛰고(cp949) 읽은 뒤
2. 계약 해제 건(`해제사유발생일`이 `-`가 아닌 행: 2020년 3,159건, 2025년 6,423건)을 제외하고
3. `시군구` 컬럼에서 자치구를 뽑아 25개 구로 묶어
4. 거래금액 ÷ 전용면적(㎡당 가격)의 중앙값과 평균 거래가, 거래건수를 계산합니다.

### ⚠️ 2005년 데이터 주의
2005년 파일에는 **7~12월 거래 104건**뿐이고, 25개 구 중 4곳(종로·중·서대문·서초)은 거래가 없으며
17곳은 10건 미만입니다. 그래서 2005년 집값은 **참고용**으로만 표시하고(지도에 건수 표기, 차트는 빈 점),
집값 증가율과 서울 평균 비교는 2010년을 기준으로 계산했습니다. 인구는 2005년 값이 정상이라 2005→2025 그대로 씁니다.

## 데이터 다시 만들기

```bash
pip install pandas
python scripts/build_data.py <원본 CSV 폴더>
```

## 실행 방법

```bash
python -m http.server 8000   # 브라우저에서 http://localhost:8000
```

GitHub Pages 배포: 저장소에 push → Settings → Pages → `main` / `(root)`.
(지도 타일과 경계 GeoJSON은 인터넷 연결이 필요합니다.)

## 기능

- 인구 점 + 집값 색 동시 표시 (토글), 5개 시점 슬라이더/재생(▶)
- 점은 폴리곤 안쪽에만 찍히고, 시점이 바뀌어도 기존 점 위치는 유지되어 늘고 줄어드는 모습이 자연스럽게 이어집니다
- 구 클릭 시 상세 패널: 인구·평당가 5점 추이, 변화율, 해당 연도 아파트 뉴스 검색, 네이버부동산/호갱노노 링크
- 키보드: `Space` 재생/정지, `←` `→` 이전/다음 시점, `Esc` 패널 닫기
